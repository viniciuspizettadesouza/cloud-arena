# Pricing Normalization Mappings

Status: SPIKE-A2 complete — AWS and Azure fixture-mapped; GCP schema-mapped with fixture-dependent selectors explicitly unresolved  
Updated: 2026-08-24

This document records SPIKE-A2. It maps provider fields to the provider-neutral `PricingRecord` and defines unit handling for the MVP categories. It does not select final launch SKUs or assert service deployability.

The GCP mappings below are schema-level mappings, not fixture-validated mappings. SPIKE-A1-GCP owns exact GCP selectors and unit verification, and remains a dependency of the GCP adapter.

## Normalized record requirements

The current `PricingRecord` fields remain the public domain projection:

| `PricingRecord` field | Rule |
| --- | --- |
| `provider` | Adapter constant: `aws`, `azure`, or `gcp`. |
| `serviceCategory` | Curated Cloud Arena category, never copied from a provider family without validation. Initial values: `compute`, `database-compute`, `database-storage`, `object-storage`, `load-balancer`, and `public-egress`. |
| `serviceName` | Human-readable provider service name from the source record. |
| `skuId` | Provider product/SKU identifier. This identifies the product but is not necessarily a unique price. |
| `skuName` | Provider display name, instance/SKU name, or description. |
| `region` | Provider region code used by Cloud Arena. Global and multi-region prices require an explicit catalog mapping rather than an invented region. |
| `pricingModel` | `on-demand` for the MVP. Reserved, commitment, Spot, low-priority, and savings-plan records are excluded. |
| `unit` | Canonical billing unit after an explicit conversion rule. |
| `unitPrice` | USD price for exactly one canonical `unit`. Never a monthly total. |
| `currency` | Must equal `USD`; reject other currencies for the MVP. |
| `effectiveAt` | Provider price effective timestamp/date when supplied. |
| `retrievedAt` | UTC time when Cloud Arena fetched the source response. |
| `source` | Exact request URL or stable provider source reference plus snapshot/raw-payload linkage. |

### Required persistence fields

The current public contract is insufficient for lossless pricing and traceability. Snapshot persistence must additionally retain:

| Field | Purpose |
| --- | --- |
| `sourcePriceId` | Unique price dimension: AWS `RateCode`; Azure `meterId` plus tier start; GCP SKU/effective-time/tier-index composite. |
| `sourceUnit` | Original provider unit string before normalization. |
| `sourceUnitPrice` | Original provider numeric price before conversion. |
| `unitConversionFactor` | Canonical units represented by one source unit; defaults to `1`. |
| `tierStart` | Inclusive lower bound in canonical units. |
| `tierEnd` | Exclusive upper bound in canonical units, or absent for infinity. |
| `catalogPublishedAt` | Provider catalog publication timestamp when available. |
| `rawPayloadRef` | Reference to the immutable raw record/response retained with the snapshot. |
| `sourceAttributes` | Provider selector attributes needed to audit why the record matched. |

`skuId` cannot replace `sourcePriceId`: one AWS SKU can have several `RateCode` tiers, one Azure SKU can have several meters, and one GCP SKU can contain several tier rates.

## AWS Price List mapping

AWS regional CSV rows flatten product, term, and price-dimension data. JSON sync implementations may read the equivalent nested fields.

| Normalized field | AWS field/rule |
| --- | --- |
| `provider` | Constant `aws`. |
| `serviceCategory` | Derived from the selected offer code plus validated product attributes; do not use `Product Family` alone. |
| `serviceName` | `serviceName`. |
| `skuId` | `SKU`. |
| `skuName` | Prefer the selected instance type, volume type, or product description; retain `PriceDescription` separately in source attributes. |
| `region` | `Region Code`; require equality with the requested regional file. |
| `pricingModel` | `TermType == OnDemand` maps to `on-demand`; reject other term types for MVP snapshots. |
| `unit` | Normalize `Unit` using the unit table below. |
| `unitPrice` | Parse decimal string `PricePerUnit`; apply only a declared unit conversion. |
| `currency` | `Currency`; require `USD`. |
| `effectiveAt` | `EffectiveDate`. |
| `retrievedAt` | Fetch timestamp generated by the sync operation. |
| `source` | Regional offer-file URL plus offer `Version`. |
| `sourcePriceId` | `RateCode`; also retain `OfferTermCode`. |
| `tierStart` / `tierEnd` | `StartingRange` / `EndingRange`; map `Inf` to absent `tierEnd`. |
| `catalogPublishedAt` | Offer-file `Publication Date`. |

### AWS category selectors

| Category | Offer | Required selectors from the captured shape |
| --- | --- | --- |
| Compute | `AmazonEC2` | `Product Family=Compute Instance`, Linux, shared tenancy, used capacity, no preinstalled software, `operation=RunInstances`, chosen instance type and region. |
| Database compute | `AmazonRDS` | `Product Family=Database Instance`, PostgreSQL, chosen deployment option/instance type, operation and region. |
| Database storage | `AmazonRDS` | `Product Family=Database Storage`, PostgreSQL, chosen deployment option/volume type, operation and region. |
| Object storage | `AmazonS3` | `Product Family=Storage`, chosen storage/volume class, usage type and region. |
| Load balancer | `AWSELB` | Application load-balancer product family and operation; preserve hourly and LCU-hour price dimensions separately. |
| Public egress | `AWSDataTransfer` | `Transfer Type=AWS Outbound`, selected source region, `To Location=External`, usage type, and every tier for the SKU. |

## Azure Retail Prices mapping

| Normalized field | Azure field/rule |
| --- | --- |
| `provider` | Constant `azure`. |
| `serviceCategory` | Derived from a curated selector using service, product, meter, and SKU fields. `serviceFamily` alone is too broad. |
| `serviceName` | `serviceName`. |
| `skuId` | `skuId`; retain `productId`, `serviceId`, `meterId`, and `armSkuName`. |
| `skuName` | `armSkuName` when non-empty, otherwise `skuName`; retain `meterName`. |
| `region` | `armRegionName`; do not normalize from the display-only `location`. |
| `pricingModel` | `type == Consumption` with no Spot, low-priority, reservation, or savings-plan selector maps to `on-demand`. |
| `unit` | Normalize `unitOfMeasure` using the unit table below. |
| `unitPrice` | Use `retailPrice` for public list price. Require `unitPrice == retailPrice` for ordinary consumption records or record the discrepancy. |
| `currency` | `currencyCode`; require `USD`. |
| `effectiveAt` | `effectiveStartDate`. |
| `retrievedAt` | Fetch timestamp generated by the sync operation. |
| `source` | Retail Prices endpoint plus exact case-sensitive filter and pagination URL. |
| `sourcePriceId` | Composite of `meterId`, `tierMinimumUnits`, and effective date. |
| `tierStart` | `tierMinimumUnits`; the next row for the same meter defines `tierEnd`. |
| `tierEnd` | Next greater `tierMinimumUnits` for the same meter, or absent for the last tier. |

### Azure category selectors

| Category | Required selectors from the captured shape |
| --- | --- |
| Compute | Virtual Machines service, exact ARM SKU, non-Windows product, ordinary meter name, `Consumption`, not Spot/low-priority/Cloud Services. |
| Database compute | Azure Database for PostgreSQL service, Flexible Server compute product, exact ARM SKU, `Consumption`. |
| Database storage | Azure Database for PostgreSQL service, Flex Server Storage product, selected storage meter/ARM SKU. |
| Object storage | Storage service, Blob Storage product, selected redundancy/access tier and data-stored meter. Operation meters remain excluded unless the cost model adds request counts. |
| Load balancer | Provisional Application Gateway Standard v2 fixed and capacity meters. SPIKE-B2 must approve or replace this selector. |
| Public egress | Bandwidth service, Internet routing-preference product, Standard Data Transfer Out meter, all tier starts sorted numerically. Do not require `isPrimaryMeterRegion=true` for this evidenced meter. |

## Google Cloud Billing Catalog mapping

The following mappings come from the official `services.skus.list` schema and must be verified against real records later.

| Normalized field | GCP field/rule |
| --- | --- |
| `provider` | Constant `gcp`. |
| `serviceCategory` | Curated from service identity, SKU description, and `category.resourceFamily/resourceGroup`; exact category selectors remain unresolved. |
| `serviceName` | `category.serviceDisplayName`. |
| `skuId` | `skuId`; retain resource `name`. |
| `skuName` | `description`. |
| `region` | Resolve from `geoTaxonomy` and `serviceRegions`. Regional records must include the selected region. Global/multi-regional behavior remains unresolved per category. |
| `pricingModel` | `category.usageType == OnDemand` maps to `on-demand`; reject preemptible and commitment usage types. |
| `unit` | Normalize `pricingInfo[].pricingExpression.usageUnit`; retain base-unit fields. |
| `unitPrice` | `Number(unitPrice.units) + unitPrice.nanos / 1_000_000_000`, then apply a declared unit conversion. `displayQuantity` is presentation-only. |
| `currency` | `unitPrice.currencyCode`; request and require USD. |
| `effectiveAt` | Selected latest `pricingInfo[].effectiveTime`. |
| `retrievedAt` | Fetch timestamp generated by the sync operation. |
| `source` | `services/{serviceId}/skus` request without its API key, plus raw-payload reference. |
| `sourcePriceId` | Composite of `skuId`, pricing effective time, and tier index/start amount. |
| `tierStart` | `tieredRates[].startUsageAmount` converted into the canonical unit. |
| `tierEnd` | Next tier's start amount, or absent for the final tier. |

Also retain `baseUnit`, `baseUnitDescription`, `baseUnitConversionFactor`, and `aggregationInfo`. GCP documents the base conversion as:

```text
price per base unit = unit price / baseUnitConversionFactor
tier start in base units = startUsageAmount * baseUnitConversionFactor
```

Exact Compute Engine, Cloud SQL, Cloud Storage, load-balancing, and internet-egress SKU selectors are unresolved until authenticated catalog fixtures exist. Descriptions or category names alone must not be treated as stable identifiers.

## Canonical units and conversions

Unit normalization is explicit and category-aware. Never infer GB/GiB equivalence from a label.

| Provider source unit | Canonical unit | Conversion |
| --- | --- | --- |
| AWS `Hrs` | `hour` | `unitPrice = source price`; quantities unchanged. |
| AWS `GB-Mo` | `gb-month` | Identity for the source-labeled unit; retain `sourceUnit` because binary/decimal semantics need provider verification. |
| AWS `GB` | `gb` | Identity for the source-labeled unit. |
| AWS `LCU-Hrs` | `lcu-hour` | Identity. |
| Azure `1 Hour` | `hour` | Identity. |
| Azure `1/Hour` fixed charge | `hour` | Identity. |
| Azure `1/Hour` capacity charge | `capacity-unit-hour` | Identity; category/meter determines meaning. |
| Azure `1 GB/Month` | `gb-month` | Identity for the source-labeled unit. |
| Azure `1 GiB/Month` | `gib-month` | Identity; do not merge with `gb-month` without an explicit byte conversion. |
| Azure `1 GB` | `gb` | Identity. |
| Azure `10K` | Category-specific operation | Divide the source price by `10_000` only if normalizing to one operation; otherwise retain `10k-operations`. Not used by the initial storage-capacity estimate. |
| GCP `h` or evidenced hourly unit | `hour` | Verify exact source unit in fixture; then identity if one usage unit is one hour. |
| GCP `GiBy` | `gib` or `gib-month` | Category and aggregation determine whether time is included; use `baseUnitConversionFactor`, never a guessed multiplier. |
| Other GCP units | Unresolved | Reject until the unit has a tested conversion rule. |

Monthly hours (`730` or another convention) are workload/cost-formula inputs, not pricing-record normalization. The pricing adapter stores a per-hour price and the cost engine multiplies by the versioned monthly-hour assumption.

## Validation rules for SPIKE-A2 implementation

1. Reject non-USD records, unsupported pricing models, unknown units, non-finite/negative prices, and invalid tier bounds.
2. Preserve zero-priced tiers; zero can represent a real free allowance and is not missing data.
3. Sort tiers by start, derive exclusive ends, and reject gaps/overlaps unless a provider rule explicitly explains them.
4. Do not deduplicate by SKU alone. Deduplicate by provider, source price identity, effective time, region, and snapshot.
5. Retain all raw numeric strings/objects in the source payload; normalized decimal handling must not round before cost calculation.
6. A missing required mapping makes coverage unavailable. It never selects a vaguely similar SKU or fabricates a unit price.

## Remaining decisions

- GCP exact service IDs, SKU selectors, regions, source units, and tier examples require authenticated SPIKE-A1-GCP fixtures.
- SPIKE-B2 must settle the Azure load-balancing component before its selector is production-ready.
- SPIKE-C1 must define provider free allowances, full egress tier boundaries, and formulas.
- The persistence schema in M3-001 must add the required traceability/tier fields or equivalent normalized child records before adapters are implemented.
